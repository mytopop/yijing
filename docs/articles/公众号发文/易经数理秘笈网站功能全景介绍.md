## 一、 为什么我们要为《易经》写一套 3D 操作系统？

读过《周易》的人都会产生几个千古疑问：
- 为什么乾卦初爻是“潜龙勿用”，五爻是“飞龙在天”，二爻是“见龙在田”？龙究竟在哪里飞？
- 为什么古人说“天以六为节”、“七以法星”？
- 为什么太乙九宫有 81 宫，每一步气数的跳跃都丝毫不差？
- 为什么宇宙周天 360 度无论如何细分分割，数位之和（众和极数）永远死死锁定在“9”？

**答案只有一个：数即是理，象即是位。**

《周易》从来不是玄学迷信，而是一套**基于三大天体坐标系（赤道、黄道、白道）的离散数学全息模型**。为了让每一位易学学者、天文爱好者与现代人能够“亲手触摸”到这套算法的运转，我们打造了这款零框架依赖、毫秒级响应的纯前端 3D 拓扑交互系统。

## 二、 核心四大数理基石：天地人三元如何精确运作？

在进入具体功能前，系统为你构建了三大立体的底层数学闭环：

### 1. 三大天体坐标系立体浑天仪 (3D Armillary Spheres)
- 🔴 **赤道系统 (天 / 0° 平面)**：对应地支余数 `1 (子)、4 (卯)、7 (午)、10 (酉)`，模拟天道太阳东升西落的周日视运动；
- 🟢 **黄道系统 (地 / +23.5° 倾角)**：对应地支余数 `2 (丑)、5 (辰)、8 (未)、11 (戌)`，模拟四季更迭与大地承载的周年视运动；
- 🔵 **白道系统 (万物·月道 / -15° 倾角)**：对应地支余数 `3 (寅)、6 (巳·地户)、9 (申)、12 (亥·天门)`，模拟月相潮汐与万物生化。

### 2. 太乙八十一宫权威角标矩阵 (81 Matrix)
宏观严格遵循**洛书九宫**（戴九履一，左三右七，二四为肩，六八为足，五十居中），微观每宫内含 9 个精确气数，全网首创标注权威双行位号角标 `(宫_位)`，如 `31 (四₄)`（巽四宫四位）、`16 (七₂)`（兑七宫二位）、`1 (一₁)`（坎一宫一位）。

### 3. 毫秒级“三向实时联动”与特调弹簧震荡微交互
左栏 3D 浑天坐标仪 (28%)、中栏太乙 81 宫阵图 (36%)、右栏控制大表 (36%) 达成 100% 毫秒级双向同步！任意点击表格行或单元格，立即触发特调的 **`rowBounceShake` 0.45s 弹簧质感侧向震荡晃动**与高亮，并支持【再点取消选中】(Toggle Off)。

## 三、 十一大系统解构馆全景功能一览

整个系统由 11 个功能完备、可顶栏无缝切换的独立场馆组成：

### 🏠 01. 首页总览与天象拓扑总枢 (`index.html`)
- **核心体验**：全站 10 大门户卡片一键直达，全局 3D 浑天仪宏观巡礼，日月极星全息时空模型。

### ⚡ 02. 任意数据 12 步拆解推演流水线 (`pipeline.html`)
- **核心体验**：输入任意一个大数（如 `70000`），系统自动执行：
  `原始数值 ➔ 太乙81降维 (70000 mod 81 = 16 ➔ 兑七宫二位(七₂)) ➔ 地支12位归属 (4 卯/赤道) ➔ 三元坐标系 ➔ 众和极数`。
- 配备 5 步递算动画卡片与 $N \times k$ (1~12) 周天全量跳跃明细表，键盘输入实时计算。

### ☰ 03. 64卦拓扑与爻辞六爻解构馆 (`hexagrams.html`)
- **核心体验**：全量 64 卦下拉极速切换，自动计算错卦、综卦、互卦。
- 初爻至上爻六爻采用 **5 栏直列网格对齐**，单爻点击精准定位原文爻辞与 3D 空间投射。

### ✨ 04. 天象五大定律解构馆 (`laws.html`)
- **核心体验**：
  1. **10^n 太阳赤道守恒律**：验证太阳乘方永远锚定子午卯酉；
  2. **数 7 白道七星芒行律**：12 步 $7 \times k \bmod 12$ 跳跃明细表，揭示北斗十二芒星轨迹；
  3. **360° 周天切割归九律**：无论如何等分，众和数恒等于 9；
  4. **地支三合局**：申子辰水、巳酉丑金、寅午戌火、亥卯未木几何共振；
  5. **永静数 6 巳亥天地门**：奇入地户、偶入天门的永恒锁死机制。

### ☯ 05. 五行三元生克馆 (`wuxing.html`)
- **核心体验**：水一、火二、木三、金四、土五数理生成，相生相克 3D 光轨闭环与天干地支映射。

### 📜 06. 九宫七输入通用推演解构馆 (`jiugong_qi.html`)
- **核心体验**：支持 7 行通用参数任意自定义，推演树动画循环播放与停止（Toggle Off），整行解构定位。

### 🌀 07. 原书周天(360°) 9x9 大表馆 (`zhoutian360.html`)
- **核心体验**：100% 还原原书 P315-320 一宫+90° 至 九宫+810° 巨型大表，9x9 倍积气数单格精准点击与空间扩展。

### 🔢 08. 939697 七数律解构馆 (`qishu939697.html`)
- **核心体验**：还原原书 939697 神秘七数脉冲，观测数 3、6、9、7 在三道中的空间跳跃。

### 🌌 09. 12方位与 3 坐标系解构馆 (`coordinates12.html`)
- **核心体验**：12 地支三维坐标分解，按赤道、黄道、白道一键过滤筛选与立体投影。

### 📐 10. 用矩 81 矩阵解构馆 (`ju81.html`)
- **核心体验**：原书 1~12 矩天际行数总表、巳亥四方位质变轴、324“承受天德之筐”扣节滑动演算器、“圆出于方”多边形拟合逼近。

### 📊 11. 原书九宫纪气 9x9 大表全解馆 (`jiugong_tables.html`)
- **核心体验**：还原原书 P246-252 坎一宫至离九宫九张独立 9x9 气数大表，单格高精度定位与整行算式推导。

## 四、 零安装、秒启动：如何立即上手体验？

为了让所有人都能零门槛体验，本软件采用纯原生 Web 标准开发，**无需配置复杂的 Node.js 或打包工具**：

### 极简打开方式一：直接双击（最推荐）
1. 下载/克隆项目代码包；
2. **直接在电脑上双击 `index.html`**；
3. 即可在 Edge / Chrome / Safari 等任意现代浏览器中秒开畅玩！

### 极简打开方式二：本地静态服务器
```bash
# 克隆仓库
git clone https://github.com/mytopop/yijing.git
cd yijing

# 运行本地服务器 (Node.js 或 Python 任选)
npx http-server . -p 8080 -c-1
# 或：python -m http.server 8080
```
在浏览器输入 `http://localhost:8080` 即可体验。
