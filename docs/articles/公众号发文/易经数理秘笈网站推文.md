## 一、 我为什么要做这个项目？

读过《周易》的人都会产生几个千古疑问：

<div style="text-indent: 0 !important; text-align: left !important; font-size: 14px; font-weight: 700; color: #166534; margin-top: 18px; margin-bottom: 6px;">【天象四问 · 叩问千年之谜】</div>

<div style="margin: 6px 0; text-indent: 0; text-align: left;">
<strong>问题一 · 爻辞与空间</strong>：为什么乾卦初爻是“潜龙勿用”，五爻是“飞龙在天”，二爻是“见龙在田”？龙究竟在哪里飞？
</div>
<div style="margin: 6px 0; text-indent: 0; text-align: left;">
<strong>问题二 · 天文节律常数</strong>：为什么古人说“天以六为节”、“七以法星”？
</div>
<div style="margin: 6px 0; text-indent: 0; text-align: left;">
<strong>问题三 · 气数跳跃咬合</strong>：为什么太乙九宫有 81 宫，每一步气数的跳跃都丝毫不差？
</div>
<div style="margin: 6px 0; text-indent: 0; text-align: left;">
<strong>问题四 · 终极归九之谜</strong>：为什么宇宙周天 360 度无论如何细分分割，数位之和（众和极数）永远死死锁定在“9”？
</div>

答案只有一个：<strong>数即是理，象即是位</strong>。

千百年来，后世注易者大多抛弃了最根本的“数”与“象”，只在文字义理上打转，导致《周易》沦为不可捉摸的玄学。

我做这个项目的初心非常纯粹：<strong>破除迷信，还周易以理性与科学</strong>。我们要用现代计算机技术，把先贤在没有计算机的年代仅凭算筹推演出的浩瀚宇宙模型，直观地呈现在每一个现代人眼前，让大家真正看懂中国古人眼中的数字宇宙。

## 二、 这个系统能帮你做什么？

《周易》从来不是二维平面上的静态文字，而是一套基于三大天体坐标系（赤道、黄道、白道）的立体动态模型。这个开源系统主要为您提供以下核心功能：

<div style="text-indent: 0 !important; text-align: left !important; font-size: 14px; font-weight: 700; color: #166534; margin-top: 18px; margin-bottom: 6px;">【一 · 3D 全息浑天仪空间模型】</div>

将《周易》六十四卦、三百八十四爻辞的运动规律，完整映射到 3D 浑天坐标球仪上。系统将太阳周日视运动（赤道）、周年四季视运动（黄道）与月相交织（白道）实时同屏渲染，用户可以任意旋转、缩放视角，直观俯瞰日月星辰与八卦方位的对应咬合。

<div style="text-indent: 0 !important; text-align: left !important; font-size: 14px; font-weight: 700; color: #166534; margin-top: 18px; margin-bottom: 6px;">【二 · 太乙八十一宫数字化大矩阵】</div>

将宏观洛书九宫与微观九格气数完整数字化，精确标注权威位号角标（如 16 属于兑七宫二位「七₂」），让每一个气数的生成、流转与空间落位都有迹可循。

<div style="text-indent: 0 !important; text-align: left !important; font-size: 14px; font-weight: 700; color: #166534; margin-top: 18px; margin-bottom: 6px;">【三 · 通用数理推演计算器】</div>

用户可以输入任意自然数（如 70000），系统自动执行太乙 81 降维、地支 12 位归属与三元坐标系投影，秒级还原大数的空间归宿与对应天象。

<div style="text-indent: 0 !important; text-align: left !important; font-size: 14px; font-weight: 700; color: #166534; margin-top: 18px; margin-bottom: 6px;">【四 · 纯原生开放与完全可验证】</div>

整个系统完全基于纯前端原生标准开发，所有算法全部是透明开放的纯数学逻辑，没有任何封闭黑盒，经得起任何学者与爱好者的推导与验证。
